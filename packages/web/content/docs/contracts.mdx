## The live proof

One command proves the whole promise on Arc mainnet: a supplier bills 1 USDC, and the payer settles it from bitcoin in one signature, with the bitcoin pledged and not sold.

```bash
node packages/contracts/prove-it/prove-it.mjs
```

That is a dry run: every step is simulated from a real mainnet block with `eth_simulateV1`, so balances, the Morpho market and the price feed are live, and nothing is signed or sent. The same script with `--broadcast` sends it for real. It checks the chain id is 5042 before anything else, and it exits 0 only if every check passes: the supplier's USDC rose by exactly the bill, `BillPaid` came from AdagBills, the Memo carried the right bill and reference, and the payer's bitcoin, in the wallet plus pledged, did not change.

It was first run for real on 25 September 2026:

| Supplier writes bill #1: 1.00 USDC, reference ADAG-PROOF-0001 | [`0x13fb...f888`](https://explorer.arc.io/tx/0x13fb435c909476dc6e1da618d43fc3f81b856e3d97c52cdb1f948904d20af888) | 196,734 | 0.004131 USDC |

Read back from the chain afterwards: bill #1 is Paid, the supplier's USDC rose by exactly 1.000000, and the payer's Morpho loan sits at 38.08% of the bitcoin's value, exactly the position Adag recorded. The loan was left open on purpose, so the app has a real bitcoin-backed position to show.

## The attack suite

```bash
node packages/contracts/prove-it/attack.mjs
```

This tries to break the live contract, with the demo wallet's real Morpho loan, in 18 simulated attacks: paying a paid bill again, re-borrowing the same shares against less bitcoin, new debt past 40%, paying your own bill, fake currencies, zero amounts, over-long references, cancelling someone else's bill, paying without an allowance, a 25% price drop, and a lying RPC. Nothing is signed or sent. It prints each attack, what should stop it and the decoded revert, and exits 0 only if every row behaves as the threat model says. The full results are on [Audit status](/docs/security/audit-status), and you can [try some yourself](/docs/security/break).

## Reading Adag from your own code

The ABI is in the repository at `packages/contracts/deployments/AdagBills.abi.json`. Amounts are integers in base units: 6 decimals for USDC and EURC, 8 for cirBTC. A bill's status is `0` None, `1` Open, `2` Paid, `3` Void. Treat a bill as paid only from `bill(id).status`, or from a `BillPaid` event emitted by AdagBills' address. A `Memo` event on its own proves nothing.
